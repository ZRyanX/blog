从主流学术期刊网站（Elsevier ScienceDirect、SpringerLink、Nature、Wiley 等）自动识别并批量下载文章的补充数据 / 附表文件，如 xlsx、xls、csv、zip、docx、pdf 等。支持处理动态页面与复用浏览器认证会话。

Features核心能力

🪜 六级下载管线

Tier A、Tier 0、Tier 1、Tier 2、Tier 3-Auto、Tier OA 六级兜底；Tier 3-Auto 内按 BrowserSkill → CDP → 有头浏览器自动接管；另有 Crossref 多出版商回退与 Figshare / ScienceBase / GSA / DiVA 仓储解析。

🔍 智能过滤

自动识别真实数据文件，排除插图、参考文献等干扰。

📝 MarkItDown 副本

--convert-markdown 把附表转成 Markdown 副本，原始文件不受影响；支持多行合并表头展平与 zip 内表格递归转换，需另装 requirements-conversion.txt（.doc / .ppt 除外）。

🗂️ 自动重命名归档

用 Unpaywall / OpenAlex / CrossRef 查询文献标题，规范化命名文件夹。

✅ 完整性检查

核对文件数、S/A 表编号和每个补充区块，无法证明完整时会保留缺漏提示。

🔐 多种认证

Elsevier API Key、机构校园网 / InstToken、浏览器 Cookie 注入，复用已有登录态。

Pipeline下载链路：六级怎么兜底

Tier A · Elsevier API

极速，需 API 密钥与校园网 IP 或 InstToken。

Tier 0 · Elsevier CDN 直连

无需认证，探测 mmc*.xlsx/pdf/zip 文件。

Tier 1 · 期刊直接链接

基于 Requests 会话，带 Cookie 下载；自动修复中文文件名与 .bin 扩展名。

Tier 2 · Scrapling 隐匿渲染

用于动态页面，自动拦截阻塞渲染的第三方挂起域名。

Tier 3-Auto · 自动分级浏览器接管

遇 401 / 403 或 Cloudflare 拦截、或候选不完整时，在 60 秒接管预算与 150 秒阶段预算内按顺序尝试：已就绪的 BrowserSkill → 本地活动 Chrome（CDP）→ 独立有头浏览器。可用 --no-bsk 单独关闭 BrowserSkill 一路。

Tier OA · 开放获取与仓储穿透

Unpaywall 与 OpenAlex（PMC / Europe PMC），以及 Figshare、ScienceBase、GSA、DiVA 深度解析。

另外还有 Crossref 多出版商回退：主站无结果或无订阅权限时，自动尝试同一 DOI 的其他出版商。

Quick Start快速上手

pip install -r requirements.txt
scrapling install

# 轻量版：直接下载一篇文献的附表
python scripts/journal_downloader.py "https://doi.org/10.1016/j.oregeorev.2022.104949"

# 高级版：多级加速，适合 Elsevier / ScienceDirect 批量下载
python scripts/scansci_supp_downloader.py "10.1016/j.oregeorev.2026.107349"

# 复用日常浏览器登录态（CDP）
python scripts/scansci_supp_downloader.py "<url_or_doi>" --cdp

# 用 BrowserSkill 协同，免配调试端口
python scripts/journal_downloader.py "<url_or_doi>" --bsk

# 只列出候选附件，不下载
python scripts/scansci_supp_downloader.py "<url_or_doi>" --list-only
