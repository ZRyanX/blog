从 Zotero 选中条目、本地 PDF、期刊网页或 DOI 中自动定位、识别、核验并提取复杂科学表格，导出为出版级 Excel（.xlsx）。学术表格常有无边框 / 三线表、跨行跨列、多数值挤压、上下标与公差、多级复合表头、跨页续表等复杂排版，单一工具很容易串行、漏列或丢数据。这里的思路是：能在线高保真直取就绝不走 OCR；本地以 PaddleOCR 和 MinerU 结构化抽取为主，9 引擎投票与 TEDS 仲裁作兜底；复杂扫描件交给视觉 AI 接管。

Features核心能力

🌐 在线 HTML / XML 直取

arXiv 官方 HTML、NCBI PMC 开放获取 JATS XML、Elsevier XOCS XML（需 API Key）直取，覆盖 Wiley、Springer / Nature、Taylor & Francis、ACS、MDPI、Frontiers 等多家出版商与知网专属适配；附表提取为有界集成，走 journal-supp-downloader。

🗳️ MinerU 主抽取 · 9 引擎投票兜底

原生 PDF 先走结构树快速通道 → MinerU 结构化主抽取 → 本地双向数值门禁；未覆盖或未通过时才回退到 9 引擎投票与 IBM TEDS 仲裁（共识阈值 ≥ 0.75，低于 0.90 触发视觉 AI 核验）。

🤖 视觉 AI 接管

RapidTable 快速救援 → DocLayout-YOLO + PP-DocLayoutV3 布局集成 / PP-StructureV3 切图 → PaddleOCR-VL-1.6 或 TeleOCR 重构 → IBM Docling 纯本地离线备用；并有防回归门禁，拒绝用更差的 OCR 结果替换原生表格。

🧹 7 阶后处理

A 直通保护、B 碎片过滤、C 表头 SMART 展平、D 多数值展开、E 公式注入防御、F 噪声与脚注隔离、G 表号规范化。

🔗 跨页续表拼接

MinerU 四路联合判定与断裂单元格合并，DeepDoc / MinerU 三路单调 DP 对齐，横向分块表格按行拼接；无法验证对应关系时保留独立片段、不硬拼。

📈 出版级 Excel 导出

富文本原生保真上下标，自适应列宽，表头主题与斑马纹，注入 Dublin Core 元数据。

Pipeline提取链路：从输入到 Excel

1 · 输入

Zotero 条目、本地 PDF、批量目录 / 清单、在线 URL / DOI。

2 · 在线直取（优先）

arXiv HTML、PMC JATS XML、Elsevier XOCS XML 等权威源直取（arXiv 零 OCR 误差）；与 PDF 的声明清单逐项核对，缺失或截断的表由本地管线补齐后无损合并。

3 · 本地 PDF 深度提取

结构树快速通道 → MinerU 结构化主抽取 → 本地双向数值门禁；未覆盖或未通过时回退 9 引擎投票 + TEDS 仲裁；扫描件与低置信度页走三阶段视觉 AI。

4 · 质检与后处理

7 阶清洗、跨页拼接；OmniDocBench 标准化评测，LLM 语义门禁为可选项（--enable-llm，默认关闭）。

5 · 导出与联动

出版级 Excel；可选挂回 Zotero 条目子附件并生成 Better-Notes 预览笔记。

Quick Start快速上手

git clone https://github.com/ZRyanX/zotero-table-extractor.git
cd zotero-table-extractor
pip install -r requirements.txt
playwright install chromium

# 交互式配置向导（推荐）
python setup_paths.py

# 单篇 PDF 表格提取
python scripts/extract_zotero_table.py --pdf "/path/to/paper.pdf" --output "/path/to/output_dir"

# 在线文献 URL / DOI 提取
python scripts/extract_zotero_table.py --pdf "https://doi.org/10.1016/j.oregeorev.2022.104949" --output "./output"

# Zotero 全库一键批量提取
python scripts/batch_run.py --db-path "~/Zotero/zotero.sqlite" --paper-tables "~/paper_tables" --workers 4 --resume
